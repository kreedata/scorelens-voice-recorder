How this tab works

  1. The recorder shows you a basketball scenario below.
  2. Tap Start, then speak how you'd narrate it as the scorer (e.g. "kai for three").
  3. Tap Stop when you're done speaking.
  4. The transcript appears in the textarea — fix any words Web Speech got wrong.
  5. Tap Save & Next to commit and advance, or Skip to move on without saving.

When to use this: you don't have a game in front of you (couch, lunch break) and want to top up the corpus with the 50 prompts that cover edge cases real games might miss. Each prompt's expected parse is pre-defined — labelling is automatic.

How this tab works

        
During the game (or while watching a basketball video):

        
    
          
  1. Tap Start utterance just before each play you want to capture.
    2. 
          
  2. Speak naturally as you'd narrate it ("twenty-three drains it from deep").
    3. 
          
  3. Tap Stop. The utterance is saved with a timestamp into the Captured list below.
    4. 
          
  4. Repeat for every play you want in the corpus. Aim for 30–80 utterances per game.
    5. 
        

        
After the game (label phase, ~10 min):

        
    
          
  1. Scroll to the Captured list. The first row opens in the Label expected parse card automatically.
    2. 
          
  2. Tap an event button (2PT make, AST, etc.), enter the jersey, pick the side.
    3. 
          
  3. Tap Save & next until every captured row is labelled.
    4. 
          
  4. When done, switch to Export to download the .jsonl.
    5. 
        

        
When to use this: at a real game OR with a basketball video playing. Captures real speech patterns the prompted mode can't.

How this tab works

        
    
          
  1. Tap Download .jsonl — your phone saves the file to Files → Downloads.
    2. 
          
  2. Rename it now in the Files app to something dated like voice_2026-05-15_vs-cougars.jsonl (long-press → Rename). Otherwise the next game's download collides.
    3. 
          
  3. AirDrop / email / iCloud the file to your laptop within the day. iOS Safari can evict IndexedDB after ~7 days of no PWA visits.
    4. 
          
  4. Tap Clear all saved rows so the next game starts clean.
